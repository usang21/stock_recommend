# 재료(뉴스/공시) 판단 기준

이 문서는 전략1(상한가 + 재료 + 거래량)의 2단계에서 종목별 뉴스/공시 원문을
읽고 "재료 유무"와 "호재/악재"를 판단하는 기준이다. 이 판단은 사람이 개입하지
않고 자동으로 최종 처리되므로, 아래 기준을 벗어나는 임의 판단을 하지 않는다.

이 파일을 수정하면 다음 리포트 생성부터 새 기준이 적용된다 (DESIGN.md §8).

## 입력

종목별로 제공되는 최근 며칠 내 뉴스(여러 언론사, 중복 보도는 대표 기사 1건으로 정리됨)
원문과 공시(DART) 제목/보고서명이 주어진다. 키워드 매칭이 아니라 원문 전체 내용을 읽고
판단한다.

## 판단 절차

1. 주어진 뉴스/공시 중 해당 종목의 주가에 영향을 줄 만한 재료성 정보가
   하나라도 있는지 확인한다.
2. 재료가 전혀 없으면 `verdict: "none"`으로 응답한다.
3. 재료가 있으면 아래 호재/악재 기준에 따라 `verdict: "positive"` 또는
   `verdict: "negative"`로 분류한다. 호재/악재가 섞여 있으면 상한가를
   기록한 시점과 더 밀접하게 관련된 재료, 또는 더 최근/비중이 큰 재료를
   기준으로 판단한다.
4. 애매하여 호재/악재를 명확히 가르기 어려운 경우 `verdict: "positive"`로
   분류한다 (과소 포함보다 과다 포함이 안전하다는 정책, DESIGN.md §4).
   단, "재료가 아예 없다"(`none`)와 "재료는 있는데 애매하다"(`positive`로
   포함)는 구분한다 — 재료 자체가 없으면 `none`이다.
5. `summary`에는 어떤 재료를 근거로 판단했는지 1~2문장으로 요약한다.
   사람이 리포트에서 이 요약과 원문 링크를 보고 최종 확인할 수 있어야 한다.

## 호재 기준

- 유상증자 (일반적으로는 희석 요인으로 분류되지만, 이 시스템에서는 명시적으로
  호재로 취급한다 — 사용자가 의도적으로 확인한 정책이며 임의로 바꾸지 않는다.
  DESIGN.md §12 참고)
- 신규계약체결
- 자사주매입
- 신고가 경신
- 예상치를 상회하는 재무성과 (어닝 서프라이즈)
- 시장점유율 증가
- 혁신 (신기술/신제품 발표 등)
- 신규 시장 진출
- MOU 체결

## 악재 기준

- 예상치를 하회하는 실적 (어닝 쇼크)
- 시장점유율 감소
- 당국의 규제 발생
- 소송 발생

## 출력 형식

각 종목에 대해 다음 JSON 하나로만 응답한다 (설명 문장 없이 JSON만):

```json
{
  "verdict": "positive" | "negative" | "none",
  "summary": "판단 근거 1~2문장",
  "usedSourceIndexes": [0, 2]
}
```

`usedSourceIndexes`는 입력으로 주어진 뉴스/공시 목록 중 실제로 판단에 사용한
항목의 인덱스(0부터 시작) 배열이다. 판단에 쓰지 않은 원문(재료와 무관한 기사
등)은 포함하지 않는다.
